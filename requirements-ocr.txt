# Optional, Day 21. Only needed if you set ocr_enabled=true in your .env
# (see app/config.py) -- OCR is off by default, since a vision call is by
# far the most expensive single operation in this pipeline.
#
# PyMuPDF renders a PDF page to a PNG image for the vision model to read
# (app/services/ocr.py's render_page_to_png). It ships prebuilt wheels for
# all major platforms (no system Poppler/Ghostscript install needed, unlike
# pdf2image), consistent with this project's "pip install and it just
# works" bias -- the same reasoning Day 1 applied when choosing pypdf over
# a Poppler-based text extractor.
#
#   pip install -r requirements-ocr.txt
