# Optional, Day 20. Only needed if you set vector_index_backend=hnsw in
# your .env (see app/config.py) -- the default backend, brute_force, is
# pure numpy and needs none of this.
#
# hnswlib has no Windows wheel for every Python version, so on a machine
# without one pip falls back to compiling its C++ extension from source,
# which requires "Microsoft Visual C++ 14.0 or greater" (the Visual Studio
# Build Tools) to be installed. That compiler requirement used to apply to
# EVERY install of this project, including users who only ever use the
# default brute_force backend -- this file exists so the hard requirement
# files (requirements.txt / requirements-dev.txt) no longer force that cost
# on everyone. Install this file only when you deliberately opt into HNSW:
#
#   pip install -r requirements-hnsw.txt
#
# app/services/vector_index.py's HnswIndex already imports hnswlib lazily
# (only inside build(), only reached when the hnsw backend is selected) and
# raises a clear RuntimeError naming this file if it's missing.
hnswlib>=0.8.0
